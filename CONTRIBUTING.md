# Contribuer à Sentinelle

Les contributions sont les bienvenues.

1. Décrivez le problème ou la proposition dans une issue avant les changements importants.
2. Gardez les changements ciblés et expliquez leur impact sur Windows 10/11.
3. N'incluez pas de données personnelles, de règles pare-feu locales, de journaux ou de chemins propres à votre machine.
4. Décrivez les vérifications effectuées et les étapes pour reproduire le problème.

Les changements qui affectent le blocage des processus ou le Pare-feu Windows doivent préciser leurs limites et éviter de promettre une protection absolue.
